Sobre o projeto

A Buy2Buy nasceu como um laboratório de front-end

Uma loja de eletrônicos fictícia, construída do zero para colocar em prática — em um projeto real e completo — tudo que venho aprendendo em HTML, CSS e JavaScript.

Por que eu criei esse portfólio

A Buy2Buy é o meu projeto pessoal de estudos front-end. Em vez de treinar com exercícios isolados, escolhi montar uma loja virtual completa — do catálogo até a finalização da compra — para enfrentar os mesmos desafios que apareceriam em um produto de verdade: responsividade, estado entre páginas, componentes interativos e organização de CSS em um projeto que só cresce.

Cada tela nasceu de um problema concreto: como montar uma navbar com efeito de vidro fosco que funcione bem no mobile, como estruturar um carrossel de produtos por marca, como manter o carrinho sincronizado entre páginas usando localStorage. Resolver esses problemas, um de cada vez, é o que me fez evoluir de fato como desenvolvedor front-end.

Início Junho / 2026 Estrutura do site, navbar responsiva e catálogo de produtos.
Conclusão Agosto / 2026 Carrinho, fluxo de pagamento e responsividade em todo o site.

O que foi construído

Navbar com menu hambúrguer e submenu com efeito de vidro fosco, catálogo de produtos agrupado por marca com carrosséis horizontais, carrinho com contador e notificação de toast, fluxo de pagamento com Pix e cartão, e página de confirmação de pedido.

HTML5 CSS3 JavaScript LocalStorage Design responsivo
